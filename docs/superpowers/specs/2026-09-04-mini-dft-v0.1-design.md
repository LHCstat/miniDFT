# Mini-DFT v0.1 设计说明

日期：2026-09-04  
状态：已在对话中确认，等待最终文档审阅

## 1. 目标

实现一个可运行、可验证、面向教学的三维周期性平面波 Kohn–Sham DFT 程序。v0.1 用于展示从晶格、平面波基组和 FFT，到 Hamiltonian、本征值问题、电子密度及 SCF 收敛的完整数据流。

本版本追求物理定义和数值归一化自洽，不用于预测真实材料性质。

## 2. 范围

### 2.1 包含

- 三维周期性晶胞；
- 非自旋极化；
- Gamma 点；
- 平面波基组和能量截断；
- 自动构造、避免密度混叠的 FFT 网格；
- matrix-free Hamiltonian；
- SciPy `eigsh` 本征值求解；
- 整数占据，每个空间轨道容纳两个电子；
- 周期余弦局域势；
- 周期高斯原子模型势；
- Hartree 势；
- LDA：Dirac 交换与 Perdew-Zunger 相关；
- 线性密度混合；
- SCF 密度与能量收敛判断；
- 模型体系电子总能量；
- Gamma 点高斯展宽 DOS；
- YAML 输入、命令行入口及结果文件；
- 单元测试、数值性质测试和端到端测试。

### 2.2 不包含

- 多 k 点采样及布里渊区积分；
- 自旋极化；
- 分数占据和有限温展宽；
- PBE 或其他 GGA；
- 真实局域/非局域赝势；
- 离子-离子 Ewald 能；
- PAW；
- Davidson、LOBPCG、Pulay 或 Kerker；
- 几何优化、力和应力；
- 对真实材料能量或能带的定量预测。

## 3. 关键物理约定

### 3.1 单位

内部统一使用 Hartree 原子单位：

\[
\hbar=m_e=e=4\pi\epsilon_0=1.
\]

YAML 允许：

- 长度：`bohr` 或 `angstrom`；
- 能量：`hartree` 或 `ev`。

输入读取后立即转换为原子单位。终端摘要和结果摘要同时给出 Hartree 与 eV。

### 3.2 晶格矩阵

实空间晶格向量作为矩阵的列：

\[
A=[\mathbf a_1\;\mathbf a_2\;\mathbf a_3].
\]

倒格矩阵为：

\[
B=2\pi A^{-T},
\]

满足 \(A^TB=2\pi I\)。分数坐标与笛卡尔坐标的关系为 \(\mathbf r=A\mathbf s\)。

### 3.3 平面波与数组形状

Gamma 点波函数展开为：

\[
\psi_n(\mathbf r)=\frac{1}{\sqrt{\Omega}}
\sum_{\mathbf G}C_n(\mathbf G)e^{i\mathbf G\cdot\mathbf r}.
\]

系数满足：

\[
\sum_{\mathbf G}|C_n(\mathbf G)|^2=1.
\]

统一数组约定：

- 整数倒格指标：`g_indices.shape == (npw, 3)`，整数；
- 笛卡尔倒格矢：`g_vectors.shape == (npw, 3)`，浮点；
- 动能：`kinetic_energies.shape == (npw,)`；
- 单能带系数：`coefficients.shape == (npw,)`，复数；
- 多能带系数：`coefficients.shape == (nbands, npw)`，复数；
- 实空间场：`field.shape == fft_grid.shape`。

每个 \(C_n(\mathbf G_j)\) 是复数标量；三维向量保存在独立的 `g_vectors[j]` 中。

### 3.4 平面波截断

保留满足下式的倒格矢：

\[
\frac12|\mathbf G|^2\le E_{\rm cut}.
\]

枚举范围根据倒格基矢和截断球严格给出，再对候选矢量按能量筛选。结果采用稳定排序，使 \(\mathbf G=0\) 和相同能量壳层具有确定次序。

### 3.5 FFT 归一化

NumPy FFT 的缩放只在 `FFTGrid` 内实现。波函数变换保证离散积分下：

\[
\int_\Omega |\psi|^2d\mathbf r
\approx\frac{\Omega}{N_{\rm grid}}\sum_{\mathbf r}|\psi(\mathbf r)|^2
=\sum_{\mathbf G}|C(\mathbf G)|^2.
\]

标量场的 Fourier 系数与波函数系数使用不同的物理归一化接口，防止二者混用。FFT 网格的每个方向足以表示基组差矢 \(\mathbf G-\mathbf G'\)，避免密度和局域势矩阵元的循环混叠。

## 4. 软件架构

### 4.1 输入与模型层

- `i_o.py`：YAML 解析、单位转换、校验、输出文件；
- `system.py`：不可变或受控的体系配置对象；
- `constants.py`：物理常数和单位换算。

输入错误必须指出具体字段路径、期望格式和收到的值。

### 4.2 空间表示层

- `lattice.py`：晶胞、倒格矢、体积、坐标转换；
- `basis.py`：平面波枚举、动能和 FFT 索引所需信息；
- `fft_grid.py`：网格形状、索引映射、波函数和标量场变换；
- `wavefunction.py`：归一化、正交性与实空间波函数辅助操作。

### 4.3 电子结构物理层

- `ionic_potential.py`：余弦势和周期高斯原子势；
- `hartree.py`：周期 Poisson 方程；
- `xc.py`：LDA 势和能量密度；
- `potentials.py`：组合各局域势；
- `occupations.py`：非自旋整数占据；
- `density.py`：由占据波函数构造密度；
- `energy.py`：动能及各总能量分量。

### 4.4 数值层

- `hamiltonian.py`：执行 \(C\mapsto HC\)；
- `eigensolver.py`：封装 `LinearOperator` 和 `eigsh`；
- `mixing.py`：线性混合、非负性和电子数归一化。

### 4.5 控制与展示层

- `scf.py`：唯一的 SCF 调度者；
- `dos.py`：对本征值做高斯展宽；
- `__main__.py`：命令行入口；
- `__init__.py`：公开稳定 API。

模块使用包内相对导入。导入模块不得自动运行 SCF 或打印内容。

## 5. 势与能量

### 5.1 局域外势

`cosine` 势由倒格整数模式定义：

\[
V_{\rm ion}(\mathbf s)=\sum_j A_j
\cos(2\pi\mathbf m_j\cdot\mathbf s+\phi_j).
\]

`gaussian_atoms` 势使用原子分数坐标和最小镜像距离构造周期平滑势阱。它是教学模型，不是元素赝势。

### 5.2 Hartree

密度 Fourier 分量使用：

\[
V_H(\mathbf G)=\frac{4\pi}{G^2}n(\mathbf G),\quad \mathbf G\ne0.
\]

设置 \(V_H(0)=0\)，等价于采用中性均匀背景和固定平均势规范。该假设必须在输出摘要中记录。

### 5.3 LDA

交换采用均匀电子气 Dirac 交换。相关采用自旋非极化 Perdew-Zunger 参数化。零密度和极小密度通过解析极限与安全掩码处理，不产生 `NaN`。

### 5.4 总能量

本项目报告的能量是模型外势下的电子总能量：

\[
E_{\rm model}=T_s+E_{\rm ext}+E_H+E_{xc},
\]

其中：

\[
E_{\rm ext}=\int nV_{\rm ion}d\mathbf r,
\quad
E_H=\frac12\int nV_Hd\mathbf r,
\quad
E_{xc}=\int n\epsilon_{xc}(n)d\mathbf r.
\]

它不包含 Ewald 离子能，输出中不得简称为真实材料总能量。程序还计算基于本征值和重复计数修正的等价表达，作为内部一致性诊断。

## 6. SCF 流程

1. 读取并校验配置；
2. 构造 `Lattice`、`PlaneWaveBasis` 和 `FFTGrid`；
3. 生成固定的局域外势；
4. 用均匀密度 \(n_0=N_e/\Omega\) 初始化；
5. 从输入密度构造 Hartree、XC 和有效势；
6. 构造 matrix-free Hamiltonian；
7. 求最低 `bands` 个本征态；
8. 排序并生成整数占据；
9. 构造输出密度并检查积分；
10. 计算能量分量；
11. 计算未混合密度残差；
12. 线性混合并重新归一化到目标电子数；
13. 同时检查密度 RMS 和总能量变化；
14. 收敛则返回结果，否则进入下一轮；
15. 达到最大步数时返回结构化未收敛结果，并让 CLI 以非零状态结束。

首版只接受非负偶数电子数。若电子数为零，可用于自由 Hamiltonian 等数值测试，但正常 SCF 示例使用正偶数电子数。

## 7. Hamiltonian 与本征值求解

动能在倒空间中逐元素作用：

\[
(TC)_{\mathbf G}=\frac12G^2C_{\mathbf G}.
\]

局域势通过 FFT 作用：

```text
C(G) -> psi(r) -> Veff(r) psi(r) -> [Veff psi](G)
```

`Hamiltonian` 提供单向量 `apply` 和批量 `apply_many`，并能导出 `LinearOperator`。`Eigensolver` 只依赖算子接口和维数，不依赖 SCF。正常计算使用 `eigsh(which="SA")`；极小维度测试可使用确定性的稠密回退，但生产路径不构造完整 Hamiltonian。

## 8. 输入格式

基本示例：

```yaml
units:
  length: angstrom
  energy: ev

lattice:
  vectors:
    - [5.0, 0.0, 0.0]
    - [0.0, 5.0, 0.0]
    - [0.0, 0.0, 5.0]

electrons: 2
encut: 30.0
bands: 4

potential:
  type: cosine
  amplitude: -2.0
  modes:
    - [1, 0, 0]
    - [0, 1, 0]
    - [0, 0, 1]

scf:
  max_iterations: 100
  density_tolerance: 1.0e-7
  energy_tolerance: 1.0e-8
  mixing_alpha: 0.3
  eigensolver_tolerance: 1.0e-10

dos:
  enabled: true
  points: 1000
  width: 0.1
```

所有能量字段，包括势幅、DOS 宽度和能量容差，均按 `units.energy` 解析。原子坐标采用分数坐标并限制到周期晶胞。

## 9. 命令行与输出

运行方式：

```powershell
python -m mini_dft mini_dft/input.yaml --output output
```

输出：

- `summary.yaml`：输入单位、内部参数、平面波数、网格、收敛状态、Hartree 零分量约定和最终能量；
- `scf_history.csv`：迭代号、密度残差、能量变化和各能量分量；
- `eigenvalues.csv`：能带、本征值、占据数；
- `dos.csv`：能量与 DOS；
- `fields.npz`：密度及各实空间势；
- `wavefunctions.npz`：倒格指标、倒格矢及复波函数系数。

终端输出简洁的 SCF 表格和最终摘要。文件写出采用明确数据类型，复杂数组不转换为不可恢复的文本表示。

## 10. 错误处理与诊断

程序在边界处检查：

- YAML 顶层和嵌套字段；
- 单位名称；
- 晶格矩阵形状、有限性和非零体积；
- `encut`、带数、电子数、混合参数和容差范围；
- 占据带数不超过求解带数；
- 求解带数与平面波维数相容；
- 数组形状和有限值；
- 波函数正交性；
- 密度非负性和积分电子数；
- Hamiltonian 输入输出形状；
- SCF 是否真正收敛。

非法输入抛出带字段上下文的 `ValueError`。本征值求解失败保留 SciPy 原异常作为异常链。未收敛不是静默成功：库 API 返回 `converged=False`，CLI 写出诊断后返回非零退出码。
