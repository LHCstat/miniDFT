# Mini-DFT v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable and numerically verified educational Gamma-point plane-wave Kohn-Sham DFT package with two model local potentials, SCF, model electronic energy, DOS, YAML I/O, CLI, examples, tests, and reports.

**Architecture:** Use small typed data objects and focused modules. `SCFRunner` owns orchestration; spatial, physical, and numerical modules expose pure or narrowly stateful interfaces. Plane-wave coefficients and real-space fields are connected only through `FFTGrid`, which owns all NumPy FFT normalization.

**Tech Stack:** Python 3.11+, NumPy, SciPy, PyYAML, pytest, standard-library argparse/csv/dataclasses/pathlib.

**Spec:** `docs/superpowers/specs/2026-09-04-mini-dft-v0.1-design.md`

## Global Constraints

- Internally use Hartree atomic units only.
- Accept `bohr|angstrom` for input length and `hartree|ev` for input energy.
- Internal lattice vectors are columns and satisfy `A.T @ B == 2*pi*I`.
- Support Gamma point, non-spin-polarized even electron counts, and integer occupations only.
- Use a matrix-free production Hamiltonian; a dense matrix is allowed only as a tiny-dimension eigensolver fallback and in tests.
- Report `T_s + E_ext + E_H + E_xc` as model electronic energy, never as a real-material total energy.
- Set the Hartree `G=0` component to zero and record the neutral-background convention in output.
- Importing modules must not run calculations or print.
- Preserve the user's uncommitted `日志.md` change and do not include it in commits.
- Every implementation task follows red-green-refactor testing and ends with targeted regression tests.

@dataclass(frozen=True)
class Lattice:
    A: np.ndarray

    @classmethod
    def from_row_vectors(cls, vectors: ArrayLike) -> "Lattice":
        return cls(np.asarray(vectors, dtype=float).T.copy())

    @cached_property
    def B(self) -> np.ndarray:
        return 2.0 * np.pi * np.linalg.inv(self.A).T
```

def normalize_coefficients(coefficients: np.ndarray) -> np.ndarray:
    coeff = np.asarray(coefficients, dtype=np.complex128)
    norms = np.linalg.norm(coeff, axis=-1, keepdims=True)
    if np.any(norms == 0):
        raise ValueError("coefficients: zero-norm wavefunction")
    return coeff / norms

def overlap_matrix(coefficients: np.ndarray) -> np.ndarray:
    return coefficients.conj() @ coefficients.T
```

```python
@dataclass(frozen=True)
class Hamiltonian:
    basis: PlaneWaveBasis
    grid: FFTGrid
    local_potential: np.ndarray

    def apply(self, coefficients: np.ndarray) -> np.ndarray:
        kinetic = self.basis.kinetic_energies * coefficients
        psi = self.grid.coefficients_to_real(coefficients)
        local = self.grid.real_to_coefficients(self.local_potential * psi)
        return kinetic + local
```
